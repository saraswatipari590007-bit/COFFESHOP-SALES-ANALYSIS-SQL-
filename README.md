# ☕ CoffeeShop Sales Analysis Using SQL

## 📌 Project Overview

The **CoffeeShop Sales Analysis** project focuses on analyzing coffee sales data using SQL to generate meaningful business insights.

The project uses a relational database named `COFFEESHOP`, consisting of four tables: City, Customers, Products, and Sales.

The main objective is to analyze coffee consumption, revenue generation, product performance, and customer purchasing behaviour across different cities.

## 🎯 Project Objectives

- Estimate the number of coffee consumers in each city.
- Analyze total revenue generated from coffee sales.
- Identify the best-selling coffee products.
- Analyze customer purchasing patterns.
- Calculate the average sales amount per customer in each city.
- Identify the top 3 selling products in each city.
- Find unique customers purchasing coffee products.
- Identify and handle duplicate records.

## 🗂️ Database Structure

**Database Name:** `COFFEESHOP`

The project consists of the following four tables:

| Table Name | Description |
|---|---|
| `city` | Contains city information, population, and city ranking. |
| `customers` | Contains customer details and city information. |
| `products` | Contains coffee product details. |
| `sales` | Contains coffee sales transaction records. |

## 📊 Business Questions & SQL Analysis

The following business questions were explored in this project:

**1. Coffee Consumers Count**
- How many people in each city are estimated to consume coffee, assuming 25% of the population drinks coffee?

**2. Total Revenue from Coffee Sales**
- What is the total revenue generated from coffee sales across all cities in the last quarter of 2023?

**3. Sales Analysis**
- How many units of each coffee product have been sold?

**4. Customer Analysis**
- How many unique customers are there in each city who have purchased coffee products?

**5. Average Sales Analysis**
- What is the average sales amount per customer in each city?

**6. Top-Selling Products**
- What are the top 3 selling products in each city based on sales volume?

**7. Duplicate Records**
- How can duplicate records be identified and removed from the database?

## 💡 Key SQL Techniques

Some important SQL techniques applied in this project include:

- **JOIN:** Combining multiple tables to retrieve meaningful information.
- **GROUP BY:** Summarizing sales and customer data.
- **Aggregate Functions:** Calculating revenue, total sales, and average values.
- **CTE:** Simplifying complex SQL queries.
- **DENSE_RANK():** Ranking products based on sales volume within each city.
- **Date Functions:** Filtering sales data by year and quarter.
